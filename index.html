How to use your own Spotify Developer App

Spotify limits apps in Development Mode to 25 registered users. If you're playing with more people, create your own free Spotify Developer App and enter your Client ID below — then everyone can connect without being added manually.

  1. Go to developer.spotify.com/dashboard and create a new app.
  2. Enable the Web API and Web Playback SDK APIs.
  3. In the app settings, add this Redirect URI:
    https://thorsten-klein.github.io/universal-callback/index.html
  4. Copy your Client ID and paste it into the field below, then click Connect.
